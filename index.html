PlayTime 지원

PlayTime은 플레이한 게임을 간단히 기록하는 앱입니다.

자주 묻는 질문

기록은 어디에 저장되나요?
모든 기록은 기기 안에만 저장되며 외부 서버로 전송되지 않습니다. 앱을 삭제하면 기록도 함께 삭제되니, 필요하면 CSV로 내보내 두세요.

여러 게임을 한 번에 등록할 수 있나요?
목록 화면 툴바의 CSV 버튼에서 양식을 내려받아 작성한 뒤 가져올 수 있습니다.

위젯은 어떻게 추가하나요?
홈 화면을 길게 눌러 편집 모드로 들어간 뒤 + 버튼에서 PlayTime을 찾아 추가하세요. 진행 중인 게임이 표시됩니다.

문의

버그 제보나 기능 제안은 GitHub Issues에 남겨 주세요.
